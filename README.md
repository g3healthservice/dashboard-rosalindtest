# Plataforma RosalindTest — rastreio de câncer de mama por biópsia líquida

Painel de apoio à decisão (G3 Health Service) para secretarias de saúde: população-alvo (mulheres 40–74, Censo 2022),
funil e custo-benefício por município/estado, marco legal de teste *in house* e geração das peças de instrução
(proposta, apresentação, nota técnica, ETP, TR, MROSC, CPSI, TCLE). Modelos editáveis em `modelos/`.

Publicado em https://g3healthservice.github.io/dashboard-rosalindtest/
